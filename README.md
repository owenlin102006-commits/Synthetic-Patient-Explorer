# Synthetic Patient Explorer

## 合成病人資料查詢系統

A bilingual web application for exploring synthetic electronic health records generated by Synthea.

本專題使用 Synthea 產生合成病人資料，透過 Python 匯入 SQLite 資料庫，並使用 FastAPI 與 HTML、CSS、JavaScript 建立病人資料查詢網站。

**本專題僅使用合成資料，不包含真實病人個資或醫療紀錄。**

## 1. 專題功能 / Features

- 病人清單查詢（Patient List）
- 性別與年齡篩選（Gender and Age Filters）
- 病人基本資料（Patient Details）
- 就診時間軸與診斷紀錄（Encounter Timeline and Diagnoses）
- 病人性別分布統計圖（Gender Distribution Chart）
- 檢驗與觀察紀錄（Observations）
- 用藥紀錄（Medications）
- 繁體中文／英文介面切換（Bilingual Interface）
- FHIR JSON 與 SQLite 病人 ID 一致性驗證

## 4. 安裝環境 / Requirements

開發環境：

- Windows 11
- Python 3.14
- Java JDK 21
- Gradle
- Git
- VS Code
- Synthea

### 安裝 Python 套件

在專案根目錄執行：

```powershell
py -m pip install -r backend/requirements.txt
```

至少需要 FastAPI 與 Uvicorn。

## 5. 產生 Synthea 合成資料

從 [Synthea 官方儲存庫](https://github.com/synthetichealth/synthea) 下載或複製原始碼。在 Windows PowerShell 中切換到 Synthea 專案根目錄（包含 `gradlew.bat` 的資料夾）。

在 `src/main/resources/synthea.properties` 中啟用 CSV 與 FHIR JSON 輸出。

```properties
exporter.csv.export = true
exporter.fhir.export = true
```

在 Synthea 專案根目錄執行以下指令。

```powershell
.\gradlew.bat run --args="-p 100 -s 2026 -r 20261101"
```

- `-p 100` 設定人口規模。
- `-s 2026` 設定隨機種子。
- `-r 20261101` 設定參考日期為 2026-11-01。

從 Synthea 的 `output/csv/` 將下列檔案複製到本專案根目錄下的 `data/raw/`。

- `patients.csv`
- `encounters.csv`
- `conditions.csv`
- `observations.csv`
- `medications.csv`

將同一次生成的 FHIR JSON 檔案從 Synthea 的 `output/fhir/` 複製到本專案根目錄下的 `data/fhir/`。若目的資料夾尚未存在，請先建立。

`-p` 設定的人口規模可能與 `patients.csv` 的實際資料筆數不同。本次生成與驗證使用同一批資料，共有 140 位病人。即使使用相同的 seed，不同 Synthea 版本或設定也可能產生不同筆數。現有紀錄未註明本次使用的 Synthea 版本或 Git commit。

## 6. 建立與匯入 SQLite

在專案根目錄執行：

```powershell
py -m backend.database
py scripts/import_data.py
```

匯入順序：

1. patients
2. encounters
3. conditions
4. observations
5. medications

本次資料匯入結果：

| Table           |           Records |
| --------------- | ----------------: |
| patients        |               140 |
| encounters      |             9,870 |
| conditions      |             5,324 |
| observations    |           110,590 |
| medications     |             7,876 |
| **Total** | **133,800** |

匯入程式會啟用 SQLite 外鍵約束，在同一筆交易內先依子表到父表的順序清除這五張表的舊資料，再依上述順序匯入 CSV。提交前執行 `PRAGMA foreign_key_check`，檢查資料庫結構中已宣告的外鍵。若匯入或檢查失敗，程式會回滾這筆交易。程式會輸出各表的 SQLite 筆數。FHIR 與 SQLite 的病人 ID 集合比對請見第 9 節。

## 7. 啟動後端 API

在專案根目錄執行：

```powershell
py -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

API 文件：

http://127.0.0.1:8000/docs

主要 API：

- `GET /api/patients`：查詢病人清單
- `GET /api/patients?gender=F`：依性別篩選
- `GET /api/patients?min_age=20&max_age=40`：依年齡篩選
- `GET /api/patients/{patient_id}`：查詢病人詳細資料

## 8. 啟動前端網站

保持後端 API 執行中。另開一個 PowerShell 視窗，從本專案根目錄執行以下指令。

```powershell
cd frontend
py -m http.server 5500 --bind 127.0.0.1
```

在瀏覽器開啟 [http://127.0.0.1:5500/index.html](http://127.0.0.1:5500/index.html)。

也可以用 VS Code Live Server 開啟 `frontend/index.html`。請使用 `127.0.0.1:5500` 或 `localhost:5500`，頁面路徑依 Live Server 的工作區根目錄而定。

進入首頁後可以：

1. 查詢合成病人清單。
2. 依性別及年齡篩選。
3. 查看性別統計圖表。
4. 開啟病人詳細資料。
5. 查看就診、診斷、觀察與用藥紀錄。
6. 切換繁體中文與英文介面。

## 9. FHIR 與 SQLite 比對

本專題透過 Python 解析 FHIR JSON 中的 Patient 資源，再使用 SQL 查詢 SQLite 的病人 ID。

執行：

```powershell
py scripts/compare_fhir_sql.py
```

本次結果：

```text
FHIR JSON files: 142
FHIR Patient resources: 140
SQLite patients: 140
Matching patient IDs: 140
FHIR only: 0
SQLite only: 0
Exact match: True
```

結果顯示 FHIR 與 SQLite 的 140 個病人 ID 完全一致。

此驗證僅確認病人識別碼集合一致，不代表所有醫療資料欄位均已完成一致性驗證。

## 10. 資料安全與限制

- 所有病人資料均由 Synthea 合成。
- 不使用真實電子病歷。
- 生成的 CSV、FHIR JSON 及 SQLite 資料庫不納入 Git 版本控制。
- 本專題為教學與研究用途，不提供臨床診斷或醫療決策。
- 病人觀察紀錄可能包含生命徵象、檢驗數值及其他健康指標，不應全部視為實驗室檢驗。
- 網站目前主要用於本機環境展示。
